# Olist E-Commerce Delivery Performance & Process Improvement

## Project Overview

This project is an end-to-end Business Analysis case study using the Olist Brazilian E-Commerce public dataset.

The project analyzes historical e-commerce order and delivery data to identify patterns associated with late deliveries, evaluate the relationship between delivery performance and customer satisfaction, and develop data-driven recommendations for process improvement.

## Business Problem

Delivery delays can negatively affect the customer experience and may contribute to lower customer satisfaction.

This project investigates delivery performance across the Olist marketplace to identify patterns associated with late deliveries and determine areas where the delivery experience could potentially be improved.

## Project Goal

Use SQL Server and Power BI to analyze historical e-commerce order data, identify patterns associated with delivery delays and customer dissatisfaction, and translate the findings into business process improvement recommendations.

## Dataset

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains historical information about approximately 100,000 e-commerce orders and includes information related to orders, customers, sellers, products, payments, delivery, and customer reviews.
